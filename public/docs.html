Architecture

Core loop

Discover → Map → Baseline → Observe → Detect → Analyze → Decide → Control → Evidence → Remediate → Retest → Continuous Discovery.

Security boundary

Client Plane and Admin Plane are separate. Tenant identity is derived server-side. Capability entitlements are enforced server-side.

Control engine

Every decision records context, policy basis, risk, action and evidence. Simulation lets teams understand policy impact before enforcement.

Capability model

The initial 11 capabilities are compositions of reusable primitives. Aurelis can add new controls based on customer problem requests.
