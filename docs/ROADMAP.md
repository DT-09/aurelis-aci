# Capability expansion

The initial catalog is not the product boundary. Candidate future capabilities include AI discovery, AI deployment gates, AI change management, AI retirement, secrets governance, tool-use control, autonomy limits, data lineage, sensitive-data exposure, cross-border data controls, model risk, provenance, policy exceptions, approval orchestration, adversarial testing and business workflow impact.

These should be implemented as compositions of the existing core primitives and prioritized from real customer control requests.
