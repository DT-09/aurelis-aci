# API surface

Client endpoints include `/api/client/me`, `/api/client/capabilities`, `/api/client/overview`, `/api/client/events`, `/api/client/assets`, `/api/client/decisions`, `/api/client/problem`, `/api/client/control-request`, `/api/client/policy-simulate`, `/api/client/remediation`, `/api/client/retest`, `/api/client/evidence` and `/api/client/reports`.

Admin endpoints include `/api/admin/me`, `/api/admin/tenants`, `/api/admin/entitlements`, `/api/admin/invitations`, `/api/admin/control-requests`, `/api/admin/audit` and `/api/admin/system`.
